# Tiskárna MARIVA – e-shop

Statický e-shop Tiskárny MARIVA (Všechovice): trička s vlastním potiskem v konfigurátoru, mikiny, šerpy, stužky, hrnky a další produkty na poptávku.

- `index.html` úvod, `produkty.html` katalog, `produkt.html?id=…` detail s poptávkou, `konfigurator.html` návrh trička, `pokladna.html` a `dekujeme.html` objednávka
- `produkty/sortiment.js` sortiment a ceny, `produkty/katalog.js` data konfigurátoru
- `assets/` styly, skripty, písma, logo a ilustrace

Web nepotřebuje sestavení, stačí ho nahrát na statický hosting. Formuláře objednávky a poptávky jsou připravené pro Netlify Forms.
